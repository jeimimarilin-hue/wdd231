1. Site Name

Name: Electronic Components & Arduino Guide

Reason: This name clearly identifies the platform as an educational reference guide for hobbyists, students, and makers working with hardware components and microcontrollers. Inspired by prototyping platforms like Wokwi.

2. Site Purpose

The site provides a structured visual catalog and reference guide for electronic components, separating them into active and passive categories with specifications and use cases to help students and developers in their hardware projects.

3. Scenarios

  • What is the difference between active and passive electronic components?
  • Where can I find the specifications and typical uses for a specific component like a capacitor or transistor?

4. Color Scheme

The color palette provides a technical and modern aesthetic suitable for developer and electronics platforms:

  • Background (#fce4ec): Used as the main body background.
  • Text Color (#2c1a22): Used for general paragraph readability.
  • Accent Pink (#ad1457): Used for headings and section highlights.

5. Typography

Font Family: 'Montserrat', sans-serif

Application: Applied across the entire site body, headings, and descriptions to maintain a clean, professional, and contemporary look on both mobile and desktop screens.

6. Wireframe

Mobile View: Single-column stacked layout displaying a centered header title, followed by vertical sections for passive components and active components grid.

Desktop View: Expanded multi-column grid layout allowing component cards to adjust automatically side-by-side depending on screen width.
